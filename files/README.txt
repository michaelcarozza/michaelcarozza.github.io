Put your downloadable files in this folder. The site already links to these names:

  files/playwriting-resume.pdf
  files/acting-resume.pdf
  files/cv.pdf
  files/plays/<play-title>.pdf        (one PDF per play, lowercase, words joined by hyphens)

Until a file with the matching name is here, its download link on the site will show a "not found" page.
To change a link, edit the href in index.html (plays and documents) or acting.html.
