Put your downloadable files in this folder. The site already links to these names:

  files/resume.pdf                      (a version without phone, address, or other private details)
  files/plays/<play-title>.pdf          (one PDF per play)

Play files the site expects:

  files/plays/hear-the-howls-inside-my-head.pdf
  files/plays/weight.pdf
  files/plays/humiliation-ritual.pdf
  files/plays/live-stock.pdf
  files/plays/the-figaro-trilogy.pdf
  files/plays/the-weight-of-the-sun.pdf
  files/plays/for-a-muse-of-fire.pdf
  files/plays/a-film-for-two.pdf

Until a file with the matching name is here, its link on the site shows a "not found" page.
To remove a link, for example for a play you do not want public, edit index.html.
